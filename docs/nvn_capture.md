这些入口目前都由 `gfx/nvn/dm_nvn.c` 的统一占位函数返回(非空、返回 0),所以游戏会继续执行但拿不到真实 NVN 对象。

下一步按对象生命周期实现宿主侧语义并录制命令:device → queue → window → command buffer → program / texture / sampler / memory pool → 回放 Vulkan。
